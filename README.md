# Свадебный бюджет — PWA с синхронизацией через GitHub

Приложение для управления свадебным бюджетом, подрядчиками и накоплениями. Работает офлайн, устанавливается на телефон как обычное приложение. Данные синхронизируются между всеми устройствами через ваш GitHub-репозиторий.

---

## Состав файлов

- `index.html` — приложение
- `manifest.webmanifest` — описание PWA
- `sw.js` — service worker (офлайн-режим)
- `icon-*.png` — иконки
- `wedding-data.json` — файл с данными (обновляется приложением автоматически)
- `.nojekyll` — отключает Jekyll на GitHub Pages

---

## Часть 1. Размещение на GitHub Pages

1. Создайте репозиторий на github.com, например `wedding`.
2. Загрузите в репозиторий **все файлы из этой папки**, включая `.nojekyll` и `wedding-data.json`.
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится адрес: `https://ВАШ_ЛОГИН.github.io/wedding/`

**Примечание о приватности.** Бесплатный GitHub Pages работает только с публичными репозиториями — код приложения будет доступен по ссылке всем. Это не страшно: в коде нет ваших данных. Данные лежат в `wedding-data.json`, и право их менять защищено токеном. Если хотите скрыть и сами цифры — держите репозиторий приватным (Pages для приватных репозиториев требует платный план, либо размещайте приложение на Netlify, а данные — в приватном репозитории).

---

## Часть 2. Создание токена доступа

Токен — пароль, которым приложение записывает данные в репозиторий.

1. github.com → аватар → **Settings**.
2. Внизу слева → **Developer settings**.
3. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
4. Заполните:
   - **Token name**: например `wedding-app`
   - **Expiration**: срок действия — поставьте подальше (до свадьбы + запас).
   - **Repository access**: **Only select repositories** → ваш репозиторий `wedding`.
   - **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
5. **Generate token** → скопируйте токен (показывается один раз, начинается с `github_pat_`).

---

## Часть 3. Подключение синхронизации

1. Откройте приложение по ссылке GitHub Pages.
2. Вкладка **«Деньги»** → **«Синхронизация GitHub»** → **«Настройки синхронизации»**.
3. Введите:
   - **Репозиторий**: `ВАШ_ЛОГИН/wedding`
   - **Ветка**: `main`
   - **Токен**: вставьте скопированный токен
4. **«Подключить и загрузить»**.

Если в репозитории уже есть данные — приложение спросит, загрузить их или залить локальные. При первом подключении заливаются ваши текущие данные.

---

## Как работает синхронизация

- После каждого изменения данные автоматически сохраняются в GitHub (с задержкой пару секунд).
- При открытии приложения данные подгружаются из GitHub.
- Кнопка **«Синхр.»** запускает обмен вручную.
- Токен хранится только на устройстве, **не** попадает в данные и экспорт. На каждом новом устройстве вводится заново (один раз).

**Одновременное редактирование.** Если менять данные с двух устройств в одну минуту, последнее сохранение перезапишет предыдущее. Для личного использования это обычно не проблема.

## Установка на телефон

**iPhone (Safari):** ссылку → «Поделиться» → «На экран „Домой"».
**Android (Chrome):** ссылку → меню → «Установить приложение».

Работает офлайн. Офлайн-изменения отправятся в GitHub при следующем открытии с интернетом.

---

## Обновление приложения

1. Загрузите новые версии файлов в репозиторий.
2. В `sw.js` увеличьте версию кэша: `wedding-v2` → `wedding-v3`.
3. Закройте и заново откройте приложение на телефоне.

Данные не теряются — они в `wedding-data.json` и localStorage.

---

## Резервная копия

Помимо синхронизации остаётся ручной экспорт/импорт текстом (вкладка «Деньги» → «Резервная копия»).
